# FreeCellMac support site

This repository contains the public privacy policy and support pages for FreeCellMac.

## Pages

- `https://favonianpine.github.io/freecell-site/`
- `https://favonianpine.github.io/freecell-site/privacy.html`
- `https://favonianpine.github.io/freecell-site/support.html`

The pages are plain static HTML/CSS and can be hosted with GitHub Pages. In the repository settings, choose **Pages → Build and deployment → Deploy from a branch**, select `main`, and use the root directory. GitHub may take a few minutes to publish the first deployment.
